# Простой сайт с двумя страницами

Этот сайт состоит из двух страниц: главной и страницы с ссылками на социальные сети.

## Структура
- `index.html`: Главная страница с баннером "Игры" и ссылкой "Записаться".
- `links.html`: Страница с ссылками на VK и Telegram, и кнопкой "Назад" в левом нижнем углу для возврата на главную.

## Дизайн
Сайт имеет современный эстетичный дизайн в дарковом D&D стиле с фоновыми изображениями (замок на главной и кладбище на странице ссылок из папки images/), сделанными полупрозрачными для лучшего контраста. Градиентные кнопки с плавными анимациями.

## Как запустить
1. Убедитесь, что файлы `index.html`, `links.html` и `styles.css` находятся в одной папке (например, `c:\Users\speak\Desktop\тест`).
2. Откройте `index.html` в вашем веб-браузере (двойной клик или перетащите в браузер).
3. На главной странице нажмите на "Записаться", чтобы перейти на страницу с ссылками.

## Настройка ссылок
В файле `links.html` ссылки уже настроены на:
- VK: https://vk.com/paranoid_gift
- Telegram: https://t.me/paranoid_gift

Если нужно изменить, отредактируйте соответствующие href в `links.html`.

## Требования
- Современный веб-браузер (Chrome, Firefox, Edge и т.д.).

## Устранение неполадок
- Если страницы не открываются, убедитесь, что файлы находятся в одной папке.
- Если ссылки не работают, проверьте корректность URL в `links.html`.

## Дополнительный функционал
- `script.js` добавляет hover-анимацию масштабирования для кнопок.
- Внешние ссылки (VK / Telegram) открываются в новой вкладке через `target="_blank"`.
- Анимация появления контента (fade-in).
- Preload фоновых изображений для быстрой загрузки.
- Переключатель языка (RU/EN) в правом верхнем углу.
- Favicon с буквой "И" на черном фоне.
